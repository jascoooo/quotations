# Quotations

Design work for a quote archive and builder used to answer Sanctuary (Property Service) extra-works requests.

- `docs/proposal.md` – the written proposal: what is being built, the recommended route, costs, what IT needs to provide, open questions.
- `docs/design/` – the visual drafts (artboards and layout for the design canvas) and screenshots of each screen.

Nothing here is application code yet. The drafts use one real example job taken from the supplied spreadsheet; every other job on the mock-ups is invented.
