Hugging Face: one-way, inbound only Supplies the open model files the browser downloads once and keeps, and hosts the app's code as a free static page (SharePoint cannot host it directly). It never receives an email, a photo, an address, a quote or the SOR code list.
Not used for anything holding data Python apps on Hugging Face Spaces, cloud AI services (Claude, ChatGPT, Gemini), and off-the-shelf job software would all mean a third company processing tenant data on US servers. Ruled out by your rule, by Sanctuary's supplier terms (prior written consent for any sub-processor), and a UK GDPR restricted transfer besides.
