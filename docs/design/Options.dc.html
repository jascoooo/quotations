Four ways to get there Judged against your rule: no email, photo or spreadsheet data goes to any company other than you and Microsoft. Recommended path is A first, then B on top of it.
A · start here
Microsoft 365 only, no code Weeks 1–2
Power Automate files each shared-mailbox email and its photos into a job folder in SharePoint, named by work order. A Microsoft List in Board view is the four-stage board. Drag between lanes is built in; a Power Apps form (also included) if the list is too bare. An Office Script copies Sanctuary's template into the folder and writes the cells; Excel itself saves it, so nothing in the template breaks. Copilot Chat (already in your licence) summarises a report when you paste it.
Data boundaryInside your tenant
Extra cost£0 on current licences
Needs from ITMailbox access for the flow owner
FeelFunctional, not sleek
B · the screens on page 1
Browser app with AI on the PC Weeks 3–8, built on top of A
A web app written in TypeScript. No server, nothing to install: it signs you into Microsoft and talks to the same mailbox, folders and list as A. The silky board, job pack and quote builder, with drag and drop and animation. AI models from Hugging Face run inside the browser (Transformers.js): SOR code search, summary drafting, missing-detail checks. Downloaded once, never phoning home. Hosted as a free static page on Hugging Face (code only, never data), mirrored from GitHub. No Azure, no hosting of your own.
Data boundaryPC + your tenant
Extra cost£0 to run; build time
Needs from ITApp registration + consent
FeelSleek
C · if B's AI proves too small
Your own server for the heavy AI Later, only if needed
A small box on your own network (or a machine in your own Azure subscription, UK South) running Python and larger open models, including ones that can describe photos. Same screens as B; the app just asks your server instead of the browser for the hard questions. Azure is still Microsoft, but it is a new service under your agreement, so you and IT decide whether it counts as in-house.
Data boundaryYours, if IT owns the box
Extra costHardware, or £20–60 a month
Needs from ITOwn and maintain it
FeelSleek, stronger AI
D · ruled out by your rule
Python on Hugging Face, cloud AI, or job software Kept here so the reasons are on record
A Python app on a Hugging Face Space would hold tenant emails and photos on Hugging Face's US servers. Since July 2026 a Python Space also needs a paid plan, and the free tier sleeps after two days. Cloud AI services and job-management products (Joblogic, simPRO and the like) all mean a new company processing the data, and none of them output Sanctuary's exact template. Sanctuary's own supplier terms require their prior written consent for any such company, and their 2026 code of conduct bans public AI tools outright. Hugging Face still has a role in B: supplying model files and, optionally, hosting code. Never data.
Data boundaryThird party, US
Extra costFrom $9 a month
Needs from ITTransfer agreement, client sign-off
FeelSleek, but not allowed
Why A then B rather than B alone: A gives you the filing, the folders and a working board in a fortnight with nothing new to approve, and it keeps working on its own in the background. B then reads the same folders and list, so nothing is thrown away, and if B is ever unavailable the team can still work from A.
